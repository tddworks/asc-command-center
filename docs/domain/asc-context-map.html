Six bounded contexts and their integration patterns. Two core contexts in coral; everything else earns its keep around them. The entire system translates Apple's ASC API via anti-corruption layers — shown once on Release for clarity.

Core

App Catalog and Release. What ASC Command Center actually competes on: presenting the app cleanly and shipping it reliably. Heaviest investment belongs here.

Notable integrations

Xcode Cloud → Release is OHS/PL: Xcode Cloud publishes a Build via a well-known contract; Release consumes. App Catalog ↔ Release is SK: both hold a reference to the same App root — changing its shape requires coordination.

Scope decisions

TestFlight folded into Release for the strategic view. Signing & Identity, Users & Access, Developer Setup generics omitted from this level — they deserve their own lower-level map. Game Center and EU Alternative Distribution deferred until needed.
