Ubiquitous Language

Twelve load-bearing terms. Pins the Version / Build / Submission / Release quartet and resolves the Build and Review homonyms that recur across the tool.

Release — 4 terms
Version Noun · Aggregate

A specific edition of an app submitted to the App Store — identified by a marketing version string (e.g. 2.1.0) and its state in Apple's review pipeline. An app may have multiple Versions in flight at once (one Ready For Sale, one Prepare For Submission).

also called: App Store Version

not: Build — a Version ships with one Build attached, but they are distinct resources. Not a Git tag or Xcode project version either.

source: ASC API · appStoreVersions

Build Noun · Entity

The uploaded binary (.ipa / .pkg) produced by compiling the app, identified by its build number (e.g. 105). A Build exists independently of any Version and can be attached to multiple Versions over time — production submission, external TestFlight, internal TestFlight.

also called: artifact, binary

not: CI Build Run — an Xcode Cloud ciBuildRun is a CI execution. The Run produces a Build. Not the same as Beta Build — same binary resource, different lifecycle.

source: ASC API · builds

Submission Noun · Aggregate

The act of handing a Release package (a Version + its Build, plus any bundled IAPs, subscriptions, or in-app events) to Apple for review. The modern form is a Review Submission — a batch that groups multiple items into one review, replacing the legacy per-version submission.

also called: review submission, batch submission

not: Release — Submission is the request-for-review; Release is what happens after Apple approves.

source: ASC API · reviewSubmissions, reviewSubmissionItems

Release Noun · Event / Verb

The event of making an approved Version available to end users — either all at once (immediate) or gradually over seven days (phased). As a verb: to release triggers this transition.

also called: go live, ship, publish

not: Submission (the review request) or Build upload (putting the artifact on Apple's server). Nothing is "released" until Apple has approved and the release request fires.

source: ASC API · appStoreVersionReleaseRequests, appStoreVersionPhasedReleases

TestFlight — 2 terms
Beta Build Noun · Entity

A Build distributed to testers via TestFlight. Expires 90 days after upload — after which testers can no longer install or launch it. External distribution additionally requires a Beta App Review.

also called: TestFlight build

not: a production Build — same binary resource, different lifecycle and different review. The 90-day clock applies only to beta distribution.

source: ASC API · builds + buildBetaDetails

Beta Group Noun · Aggregate

A named cohort of TestFlight testers. Internal groups are drawn from the Users & Access team (up to 100) and skip Beta App Review. External groups accept invited testers (up to 10,000) and require Beta App Review per Build.

also called: tester group

not: the testers themselves — a Tester (identified by email) can belong to multiple Groups. Not a User — TestFlight testers are outside Users & Access.

source: ASC API · betaGroups, betaTesters

Customer Relations — 1 term
Customer Review Noun · Entity

A star rating (1–5) and optional text comment left by an end user on the App Store page. Scoped per territory and per version. The developer may post one Response per Review.

also called: App Store review, user review, rating

not: Apple Review — the approval process performed by the App Review team on a Submission. Same word, unrelated concept. Also not TestFlight beta feedback.

source: ASC API · customerReviews, customerReviewResponses

Monetization — 2 terms
In-App Purchase Noun · Aggregate

A paid digital good sold inside the app. Three kinds: Consumable (used up — gem packs), Non-Consumable (permanent — feature unlocks), and Non-Renewing Subscription (fixed-duration access). Each IAP has its own independent Apple review lifecycle.

also called: IAP

not: Subscription — auto-renewable subscriptions live in their own aggregate with groups and offers. Not a paid-app price — the app itself being paid is a separate pricing schedule.

source: ASC API · inAppPurchases

Subscription Noun · Aggregate

An auto-renewing entitlement. Every Subscription belongs to a Subscription Group whose tiers are mutually exclusive — a customer can only be active in one at a time. May carry Introductory Offers, Promotional Offers, Offer Codes, or Win-Back Offers.

also called: auto-renewable, auto-renewing, auto-renew

not: Non-Renewing Subscription — confusingly, that's a variant of In-App Purchase, not of Subscription. Apple's naming, not ours.

source: ASC API · subscriptions, subscriptionGroups

Signing & Identity — 2 terms
Certificate Noun · Entity

A cryptographic certificate issued by Apple that authorizes code signing. Three types: Development, Distribution (App Store), and Developer ID (direct-download macOS). Tied to an Apple ID or team.

also called: signing certificate, cert

not: Provisioning Profile — the Profile uses a Certificate plus a Bundle ID plus optional Devices. The Certificate is one ingredient; the Profile is the composition.

source: ASC API · certificates

Provisioning Profile Noun · Aggregate

The signing authority embedded into a build. Bundles together a Certificate, a Bundle ID, optional allowed Devices, and entitlements so iOS/macOS will trust and run the binary. Expires on its own clock — Profiles can go stale even when the underlying Certificate is still valid.

also called: profile, mobileprovision, .mobileprovision

not: a Certificate alone. Development profiles embed Devices; Distribution profiles don't — this is the most common source of "works on my device, fails in TestFlight" confusion.

source: ASC API · profiles

Xcode Cloud — 1 term
Workflow Noun · Aggregate

An Xcode Cloud CI pipeline definition for a Product (app or Swift package). Binds a Git reference pattern, one or more Actions (build, test, archive), and post-actions (TestFlight upload, notifications). Triggering a Workflow creates a CI Build Run which produces artifacts — and, optionally, an uploaded Build.

also called: CI workflow, Xcode Cloud workflow

not: a Build. A Workflow runs; a ciBuildRun executes; the Run uploads a Build. This is the most load-bearing homonym in ASC — one word, two aggregates in two contexts.

source: ASC API · ciWorkflows, ciBuildRuns
